# React Post Cards Pagination App

A React-based web application that displays posts in card format with pagination and card removal functionality.

This project fetches post data from a public API and displays it in a clean UI following the given wireframe requirements.

---

# Features

- Fetch posts from API
- Display **6 cards per page**
- Pagination navigation
- Remove card using **red cross icon**
- Automatically shift a new card when one is removed
- Loading screen for **5 seconds on startup**
- Clean and modular component structure
- Global state management using **Context API**

---

##  API Used

GET  
https://jsonplaceholder.typicode.com/posts
